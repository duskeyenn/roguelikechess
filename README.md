# roguelikechess v1.0

A chess game with roguelike mechanics 

## Description

This project was built entirely using Java script and vanilla CSS without any additional frameworks .

## Getting Started

### Dependencies

* node-js 

### Installing

* clone the repo
``` sh
    https://github.com/duskeyenn/roguelikechess.git

```

### How to run the program

``` sh
    cd roguelikechess
```

``` sh
    node server.js
```
